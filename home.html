Configuring your client

Modules not yet cached are redirected to proxy.golang.org. Checksums are still verified against sum.golang.org: 

go env -w GOPROXY={{ .Host }},https://proxy.golang.org,direct
{{ if .NoSumPatterns }}

Excluding checksum database

Use the following GONOSUMDB environment variable to exclude checksum database: 

GONOSUMDB={{ .NoSumPatterns }}
{{ end }}

How to use the Athens API

Use the catalog endpoint to get a list of all modules in the proxy.

List of versions

This endpoint returns a list of versions that Athens knows about for github.com/google/uuid: 

GET {{ .Host }}/github.com/google/uuid/@v/list

Version info

This endpoint returns information about a specific version of a module: 

GET {{ .Host }}/github.com/google/uuid/@v/v1.6.0.info

This returns JSON with information about v1.6.0. It looks like this:

{
	"Version": "v1.6.0",
	"Time": "2024-01-23T18:54:04Z"
}

go.mod file

This endpoint returns the go.mod file for a specific version of a module: 

GET {{ .Host }}/github.com/google/uuid/@v/v1.6.0.mod

This returns the go.mod file for version v1.6.0. As github.com/google/uuid has no dependencies, the response body looks like this: 

module github.com/google/uuid

Module sources

GET {{ .Host }}/github.com/google/uuid/@v/v1.6.0.zip

This endpoint returns a zip file with the source code of the module in version v1.6.0.

Latest

GET {{ .Host }}/github.com/google/uuid/@latest

This endpoint returns the latest version of the module. If the module has no tagged versions, it returns a pseudo-version for the latest commit.
